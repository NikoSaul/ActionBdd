Ouvre ce fichier et remplace SUPABASE_URL_ICI et SUPABASE_ANON_KEY_ICI par tes identifiants Supabase (Project Settings → API).

Puis exécute ce SQL dans l'éditeur SQL de Supabase :

create table scenes (
  id uuid default gen_random_uuid() primary key,
  title text not null,
  film text not null,
  youtube_url text,
  description text,
  transcript text,
  tags text,
  characters text,
  created_at timestamptz default now()
);

alter table scenes enable row level security;
create policy "read" on scenes for select using (true);
create policy "insert" on scenes for insert with check (true);
create policy "update" on scenes for update using (true);
create policy "delete" on scenes for delete using (true);
Remplace aussi ANTHROPIC_KEY_ICI par ta clé API Anthropic (console.anthropic.com).
